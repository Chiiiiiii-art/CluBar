# 03｜元件指南

> 共用元件在 [`src/components/ui/`](../../src/components/ui/)，從 `@/components/ui` 匯入。**先找現有元件，找不到才新增；新增的共用元件放進 `ui/` 並補本頁。**
> 每個元件寫「什麼時候用／什麼時候不用」。視覺數值見 [02-tokens](./02-tokens.md)。

## 按鈕：`Button`、`ButtonLink`、`IconButton`、`buttonClasses()`

| variant | 用在 | 規則 |
| :--- | :--- | :--- |
| `primary` | 這個畫面**唯一**最重要的行動（報名、發布、送出） | 一個畫面／一個區塊最多一個 |
| `secondary` | 其他行動、卡片層級的行動（卡片上的「卡位」） | 墨色細框 |
| `ghost` | 工具列、低強調行動 | — |
| `soft` | 情境捷徑（貼文卡上的「開放零基礎體驗：…」） | 寬度跟容器走（`w-full min-w-0`），文字截斷 |
| `danger` | 不可逆的刪除、停權 | 一定搭配確認對話框 |

- 尺寸：`md`（44px）為預設；`sm` 視覺 36px，但透過偽元素保留 44px 點擊區；`lg` 用在表單送出。
- 按鈕文字寫「動詞＋對象」：「發布活動」「取消追蹤攝影社」，不寫「確定」「是」。
- 載入中用 `loading`，不要讓按鈕消失或改變寬度。
- `IconButton` 必須有 `aria-label`（型別已強制）。

## 卡片：`Card`、`Section`、`PageHeader`

- 卡片＝細框＋`surface` 底，**不可巢狀**；卡片內分組用間距或分隔線。
- 一張卡只有一個入口：整張卡連到詳情，不在卡上放多個互相競爭的連結。
- 卡片內容上限：圖、標題、一行資訊、最多 2 個信任標籤。

### 活動卡：`EventCard`（票根）
- 票根形狀：`.ticket-stub`（globals.css）＝虛線＋兩側缺口。上半是時間、圓黑（`font-display`）活動名、社團、地點；下半（票根）是費用與最多 2 個信任標籤。
- 時間待定時寫「時間待定・投票中」，不寫空白或「TBD」。
- 不顯示報名人數。

### 貼文卡：`PostCard`（原圖）
- 圖片保留原始比例，不裁切（不在固定高度的框裡用 `object-cover`）。
- 無圖時用領域色底＋標題，不放假圖。
- 社團名稱放在圖與標題之後，是次要資訊。

### 社團標誌：`ClubMark`（非圓形扇貝模切貼紙）
- 採用 SVG 扇貝波浪模切貼紙輪廓、領域色底＋領域文字色＋深墨描邊與硬投影；無類別時依 `seed` 穩定選一個領域色。
- `round` 代表「人」（使用者頭像）：素色圓配深墨外框，與社團扇貝貼紙明確區分。

## 標籤與篩選：`Badge`、`FilterChip`、`ChipRow`

| 元件 | 用在 | 規則 |
| :--- | :--- | :--- |
| `Badge` | 靜態資訊：領域、信任訊號（零基礎可、非社員可、近 30 天活躍） | 6px 圓角；不可點 |
| `FilterChip` | 可切換的篩選條件 | 混搭貼紙輪廓（`shapeIndex`）；選中時深墨底亮黃字、`aria-pressed` |
| `ChipRow` | 一列 chip，行動版水平捲動 | 右緣漸隱提示可捲動 |

- 篩選套用後，在結果上方列出已選條件，每個可單獨移除，並提供「清除全部」（Baymard）。
- 信任標籤只能是質性描述，不可是數字。

## 表單：`Field`、`Input`、`Select`、`Textarea`、`controlClasses`

- 標籤一律在欄位上方，單欄排列（NN/g）。
- 必填與選填都要標明：「（必填）」「（選填）」。
- 錯誤顯示在欄位下方，白話說明怎麼修；用 `aria-invalid`，不只靠紅色。
- 驗證或網路失敗時**不清空**使用者輸入。
- 長表單分段（`fieldset`＋`legend`），超過 3 段時可收合，並在摘要列說明有哪些段落。
- AI 填入的欄位標示「AI 填入，請確認」；確認前不能發布。

## 分頁：`Tabs`、`tabPanelProps`

- 分頁標籤 1–2 個詞；目前分頁用至少兩種方式標示（底線＋字重）。
- 分頁之間是平行的同類內容；有先後順序的步驟用精靈式流程，不用分頁。

## 對話框：`Dialog`、`useConfirm()`

- **只確認不可逆的操作**（刪除、停權、送出交接、核准）。可以復原的操作用「已取消追蹤・復原」提示，不跳對話框。
- 標題寫出操作對象：「停權這個社團？」；說明寫後果。
- 確認按鈕寫動詞（「停權」「核准」）；破壞性操作用 `tone: 'danger'`，一般確認用 `tone: 'primary'`。
- 不預設聚焦在破壞性按鈕上。
- 禁用 `window.confirm()`（測試守門）。

## 狀態：`EmptyState`、`Skeleton`、`Notice`

| 元件 | 規則 |
| :--- | :--- |
| `EmptyState` | 1 張非圓形摺角便條貼紙＋星芒插圖（`EmptyStickerIllustration`）＋1 句說明＋1 個主要行動。 |
| `Skeleton` | 1 秒內不顯示；1–10 秒用骨架，形狀要對應真實版面；超過 10 秒用進度條（NN/g）。 |
| `Notice` | 頁面層級的提示：`info`／`success`／`warning`／`danger`；搭配圖示或文字，不只靠顏色。 |

## 導覽：`Navbar`

- 桌機頂欄＋行動版底部導覽；四個空間：別的聚、一起聚、我的聚、（登入／個人）。
- 目前所在的空間用 `aria-current="page"` 並有視覺標示。
- 固定列不可遮住鍵盤焦點。

## 功能元件（`src/components/`）

| 元件 | 什麼時候用 |
| :--- | :--- |
| `DomainIcon` | 興趣領域的 icon（依 slug），放在篩選貼紙與測驗選項前，讓領域一眼可辨。未知 slug 用通用圖形。 |
| `EventStatusTags` | 活動時間或地點還沒定時的短標籤：「喬時間」「時間待定」「地點待定」（`warning`）。不要把這些狀態寫進內文；`settledLocation()` 會把「（TBD 待定）」從地點文字去掉。 |
| `RecipeCard`／`RecipeFood` | 測驗結果的配方卡：特調或披薩，配色依 `PALETTES` 由份量大到小上色。只寫「N 份」，不寫百分比。`RecipeFood` 是純 SVG，同一份畫法也給 OG 圖用（OG 傳入色碼字面值）。 |
| 入場券（`EventPageClient` 內） | 卡位成功的確認：黃底卡片＋虛線打洞分隔＋「已卡位」蓋章；正下方只放「當日推播我」。 |

## 新增元件前的檢查

1. `ui/` 裡真的沒有可用的？能不能用 variant 擴充現有元件？
2. 只用語意 token，不用原始色階、不寫 hex。
3. 點擊目標 ≥ 44px、有可見焦點、有無障礙名稱。
4. 在本頁補一段「什麼時候用／不用」。
