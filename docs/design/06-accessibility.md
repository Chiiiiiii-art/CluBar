# 06｜無障礙檢核表

> 標準：**WCAG 2.2 AA**（W3C 正式推薦標準，2023-10）。每個新頁面或大改的頁面，PR 前逐項勾選。
> 已有自動守門的項目標 🤖（`tests/ui-design-tokens.test.ts`、`tests/authz-privacy-v2.test.ts` 等）。

## 色彩與對比
- [ ] 文字對比 ≥ 4.5:1；24px 以上或 18.66px 粗體 ≥ 3:1（1.4.3）
- [ ] 輸入框邊框、圖示、焦點框等非文字元素 ≥ 3:1（1.4.11）——輸入框用 `line-input`，不用 `border-strong`
- [ ] 不只靠顏色傳達狀態；搭配文字或圖示（1.4.1）
- [ ] 只用語意 token，不寫 hex、不用原始色階 🤖

## 鍵盤與焦點
- [ ] 所有互動元素都能用 Tab 到達、用 Enter／Space 操作
- [ ] 焦點可見（`:focus-visible` 外框）（2.4.7）
- [ ] 固定頂欄、底部導覽、底部報名列不會遮住焦點元素（2.4.11）
- [ ] 對話框開啟時焦點移入、關閉後回到觸發按鈕；Esc 可關閉
- [ ] 破壞性操作不預設聚焦

## 點擊目標
- [ ] 點擊目標 ≥ 44×44px（2.5.8 最低 24px；本專案取 44px）
- [ ] 小尺寸按鈕用偽元素擴大點擊區，不只放大視覺
- [ ] 拖曳操作有單一點擊的替代方式（2.5.7）

## 語意與名稱
- [ ] 每個表單控制項都有可讀的名稱（`label`、`aria-label`）🤖
- [ ] 只有圖示的按鈕有 `aria-label` 🤖（`IconButton` 型別強制）
- [ ] 標題層級正確（每頁一個 `h1`，不跳級）
- [ ] 分頁用 `role="tab"`／`aria-selected`；篩選 chip 用 `aria-pressed`；目前頁面用 `aria-current`
- [ ] 裝飾性圖片與插圖 `aria-hidden` 或 `alt=""`；內容圖片有有意義的 `alt`
- [ ] 錯誤欄位 `aria-invalid`，錯誤訊息以 `aria-describedby` 連結

## 動態
- [ ] 慶祝動態 ≤ 400ms，不閃爍超過每秒 3 次（2.3.1）
- [ ] `prefers-reduced-motion: reduce` 時停用或只保留透明度（2.3.3／C39）
- [ ] 不自動播放超過 5 秒的動態內容，或提供暫停（2.2.2）

## 中文排版與縮放
- [ ] `<html lang="zh-Hant">`；英文段落另標 `lang`
- [ ] 文字放大到 200% 不破版、不需水平捲動（1.4.4、1.4.10）
- [ ] 行動版輸入框字級 ≥ 16px（避免 iOS 自動縮放）
- [ ] 中文不使用斜體、不加字距

## 表單
- [ ] 標籤在欄位上方，必填／選填都標明
- [ ] 錯誤時保留輸入，訊息說明怎麼修（3.3.1、3.3.3）
- [ ] 重要或不可逆的送出有確認或可復原（3.3.4）
- [ ] 同一流程中不要求重複輸入已填過的資訊（3.3.7）

## 驗證方式
1. 鍵盤從頁首 Tab 到頁尾走一遍。
2. 行動版（390×844）與桌機（1440×900）各看一次。
3. 系統設定開啟「減少動態」再操作一次。
4. 瀏覽器縮放 200%。
