# 05｜文案與語氣

> 基礎是既有的 Smart Brevity 精簡原則（[UX 稽核 §三](../ux-audit-and-benchmark.md)）；本頁加上品牌語氣的使用範圍。

## 1. 基本原則

1. **說人話。** 用學生平常講的話，不用公文體，不用內部代號（Rebound、Jam、NRC、WIP、owner、scheduled）。
2. **先講重點。** 一句話講完一件事；標題就是結論。
3. **具體。** 「11/29（六）19:00・工程五館 A205」，不寫「近期」「某處」。
4. **不責怪、不施壓。** 不寫「你還沒…」「最後機會」「名額只剩 N 個」。
5. **歡迎新人。** 主動說「零基礎可」「非社員可」「不用帶器材」。

## 2. 貼紙簿語氣：簡潔、像學生平常講的話

| 位置 | 可以用 | 例句 |
| :--- | :--- | :--- |
| 前台頁面標題、副標 | ✓ | 「看作品，找到真正想去的社團」「從社員日常與體驗社課開始，零基礎也能輕鬆參加。」 |
| 空狀態 | ✓ | 「這裡還空著」「換個領域逛逛，找張喜歡的社團貼紙。」 |
| 篩選與探索回饋 | ✓ | 「撕掉全部」「這批看完了」「位子留好了」「已留位」 |

**絕對避免**：對使用者說教或曝光平台規則（例如「不靠讚數排序」「不顯示人數」「每個社團最多 2 則」）、多餘英文術語（如 `PASS`、`HOT`、`FAIR PLAY`）。

以下地方**一律中性、精準**：
- 表單標籤與說明、錯誤訊息
- 權限、隱私、法律相關說明
- 社團管理、治理後台
- 確認對話框

## 3. 常用句型

| 情境 | 寫法 | 不要寫 |
| :--- | :--- | :--- |
| 主要按鈕 | 動詞＋對象：「發布活動」「留個位子」「追蹤社團」 | 「確定」「送出」「OK」 |
| 確認對話框標題 | 問句＋對象：「停權這個社團？」 | 「你確定嗎？」 |
| 確認對話框說明 | 寫後果：「社團主頁與活動將無法公開檢視。」 | 「此操作無法復原，請三思。」 |
| 錯誤訊息 | 發生什麼＋怎麼做：「這個信箱不是 .edu.tw 結尾，請改用學校信箱。」 | 「輸入錯誤」「發生未知錯誤」 |
| 空狀態 | 現在的狀態＋下一步：「追蹤社團或報名活動後，通知會出現在這裡。」 | 「無資料」 |
| 時間待定 | 「時間待定・投票中」 | 「TBD」「未定」 |
| AI 草稿 | 「AI 先幫你填好了，請確認時間和地點」 | 「AI 已自動完成」 |
| 必填／選填 | 「（必填）」「（選填）」 | 只用星號 |

## 4. 用詞表

| 用 | 不用 |
| :--- | :--- |
| 別的聚／一起聚／我的聚 | 探索頁／社群頁／後台 |
| 社團現場 | 動態牆、feed |
| 近期活動 | events |
| 留位子、報名 | RSVP |
| 社員日常 | NRC、NRC Moment |
| 實作作品 | WIP、WIP Work |
| 接力回應 | Rebound |
| 跨校共作企劃 | Jam |
| 前輩請益 | Alumni Ping |
| 社長／幹部／認證社員／歷屆校友 | owner／editor／member／alumni |

## 5. 格式

- 中文與英數之間加半形空格：「Unity 2D 小遊戲」。
- 全形標點；日期「11/29（六）」；時間 24 小時制「19:00」。
- 數字用阿拉伯數字。
- 不用驚嘆號堆疊、不用 emoji 取代文字（使用者產生的內容除外）。
