# 01｜品牌與設計原則

> 所有設計決策的最上層依據。遇到規範沒寫到的情況，回到本頁的原則與形容詞表判斷。
> 依據：[提案書價值主張](../clubar-pitch-deck.md)、[價值主張對齊](./research/00-value-proposition-alignment.md)、[參考分析](./research/reference-analysis.md)。

## 1. 我們是誰

**社團聚是大專社團的內容探索與交流平台：學生看作品就能認識陌生社團。**

品牌概念是 **「社團吧台」**：下課後大家會聚過去的那張桌子。作品是擺在桌上的東西，學生是因為桌上的東西坐下來，不是因為認得招牌。

- 吧台＝**聚在一起的桌子**，不是酒、不是夜店、不是喧鬧。
- Logo 是唯一出現酒杯的地方。

## 2. 品牌形容詞（2026-11-27 定案）

| 要成為 | 不要成為 | 在介面上的意思 |
| :--- | :--- | :--- |
| **溫暖** | 冰冷、官方 | 米白紙色底、暖咖啡色文字；說人話 |
| **有活力** | 吵雜、廉價 | 熱鬧感來自作品與活動本身，不靠數字、紅點、閃爍 |
| **歡迎新人** | 小圈圈、排外 | 隨時告訴新人「零基礎可、非社員可」；不用帳號也能先看、先試 |
| **有質感** | 模板感、千篇一律 | 宋體標題、票根與杯墊的形狀語彙、手繪線條插圖 |
| **可信賴** | 花俏、不可靠 | 一致、克制；不用黑暗模式（dark pattern）、不製造急迫感 |

每個新畫面上線前，用這張表自評：五個「要成為」都說得通，五個「不要成為」都沒有沾到。

## 3. 七條設計原則

1. **內容是主角，介面是畫框。** 社團海報與照片本身就很豐富，介面用低彩度、克制的色彩襯托，不和內容搶。（Apple HIG：品牌讓位給內容）
2. **看作品認識社團。** 卡片以作品為視覺主角，社團名稱是次要資訊；任何排序都不看知名度。
3. **公平且克制。** 不顯示按讚、追蹤、人數、排名、契合度百分比；只用質性訊號。非競爭性的集體累計可以保留。
4. **有盡頭的瀏覽。** 看完就說看完了，並提供下一個主題入口；不做無限捲動、不製造「再滑一下」。
5. **先給價值，再要承諾。** 先看、先測驗、先報名，最後才請註冊或追蹤；每一步都能跳過。
6. **溫度來自細節，不來自裝飾。** 字體、圓角、動態、文案的分寸決定溫度；資訊永遠在不捲動、不 hover 的情況下就看得到。
7. **一套系統，三種溫度。** 前台（會被分享的頁面）品牌感最強；工作區（管理、我的社團）收斂；治理後台只保留色彩與字體。

## 4. 品牌表現分區

| 區域 | 頁面 | 宋體標題 | 票根／杯墊形狀 | 插圖 | 慶祝動態 | 吧台語氣文案 |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| **前台** | 探索首頁、活動頁、社團頁、Onboarding、Blend、個人足跡 | ✓ | ✓ | ✓ | ✓ | ✓ |
| **工作區** | 社團管理、我的社團、一起聚 | 頁面標題 | 活動卡 | 空狀態 | 只在成功時 | 只在空狀態與成功 |
| **治理後台** | `/admin`、評鑑列印 | — | — | — | — | — |

## 5. 絕對不做（Anti-patterns）

- 公開人氣數字、排行榜、連續天數、成就徽章（Untappd、Strava 排行榜的反例）
- 霓虹、深色派對風格（Partiful 的極繁派對風）
- Logo 以外的酒杯、酒瓶、倒酒意象
- 倒數計時、「名額只剩 N 個」等急迫感設計
- 為了模仿而套用他牌識別：Airbnb 的珊瑚紅與 3D 圖示、Blue Bottle 的極簡留白
- 用 AI 生成圖取代社團自己的作品
- 契合度、匹配分數等「給人打分數」的呈現
