# 01｜品牌與設計原則

> 所有設計決策的最上層依據。遇到規範沒寫到的情況，回到本頁的原則與形容詞表判斷。
> 依據：[提案書價值主張](../clubar-pitch-deck.md)、[v2 視覺重設研究報告](../ui-redesign/v2-tactile-research.md)、[參考分析](./research/reference-analysis.md)。

## 1. 我們是誰

**社團聚是大專社團的內容探索與交流平台：學生看作品就能認識陌生社團。**

品牌概念是 **「校園貼紙簿與社團通行證」**（Soft Neubrutalism × Tactile Sticker UI）：學生像在挑選貼進筆電或筆記本的社團貼紙一樣逛作品——卡片是立體的貼紙、社團標誌是非圓形扇貝模切章、活動是可留位的票根。

## 2. 品牌形容詞（2026-11-28 v2.5 定案）

| 要成為 | 不要成為 | 在介面上的意思 |
| :--- | :--- | :--- |
| **有活力** | 沉悶、老成 | 點陣暖紙底配高飽和朱紅、鈷藍、檸檬黃跳色；6 大領域貼紙混搭非圓形輪廓 |
| **有觸感** | 模板感、平面無聊 | `2px` 深墨實線框＋硬偏移陰影＋點擊下壓塌陷與彈簧蓋章回饋 |
| **歡迎新人** | 小圈圈、排外、說教 | 主動告訴新人「零基礎可、非社員可」；免登入先逛先報名；用學生日常口語，不對使用者講系統規則說教 |
| **有質感** | 雜亂廉價、傷眼 | 暖紙底與純白卡片托住社團海報原比例不裁切，字級與對比嚴守 WCAG 2.2 AA |
| **可信賴** | 黑暗模式、急迫焦慮 | 一致、克制；不放人氣數字、不做倒數急迫感 |

## 3. 七條設計原則

1. **內容是主角，卡片是好畫框。** 社團海報與照片本身色彩豐富，卡片用純白底＋`2px` 深墨框收斂邊界，原比例不裁切。
2. **看作品認識社團。** 卡片以作品為視覺主角，社團名稱與扇貝徽章輔助識別；任何排序都不看知名度。
3. **公平不說教。** 系統底層實作公平流與去人氣數字（不顯示按讚數、追蹤數、參加人數、排名、契合度百分比），但**不在介面上對使用者說教或唸出規則**（不寫「不靠讚數排序」「不顯示人數」「最多 2 則」）。
4. **有盡頭的瀏覽。** 看完就簡潔說「這批看完了」，並提供「換一批」或「看近期活動」入口。
5. **先給價值，再要承諾。** 先看、先測驗、先報名，最後才請註冊或追蹤；每一步都能跳過。
6. **溫度與記憶點來自觸感細節。** 非圓形扇貝社團章、混搭領域貼紙、票根缺口、摺角貼紙空狀態與彈簧微動態決定辨識度。
7. **一套系統，三種溫度。** 前台（探索首頁、活動頁、社團頁、Onboarding、Blend、個人足跡）展現完整 Soft Neubrutalism 貼紙手感；工作區（社團管理、我的社團、一起聚）收斂為清晰卡片；治理後台（`/admin`、評鑑列印）保持高密度細線表格與中性色階。

## 4. 品牌表現分區

| 區域 | 頁面 | 圓黑大標 | 墨框硬陰影 | 扇貝／貼紙語彙 | 彈簧蓋章動態 |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **前台** | 探索首頁、活動頁、社團頁、Onboarding、Blend、個人足跡 | ✓ | ✓ | ✓ | ✓ |
| **工作區** | 社團管理、我的社團、一起聚 | 頁面標題 | 主要卡片與按鈕 | 領域標籤與空狀態 | 只在成功時 |
| **治理後台** | `/admin`、評鑑列印 | — | — | — | — |

## 5. 絕對不做（Anti-patterns）

- 公開人氣數字、排行榜、連續天數、成就徽章、契合度百分比
- 向終端使用者展示「不靠讚數」「不顯示人數」「最多兩則」等平台內部規則說教文案
- 霓虹派對黑底、倒數計時、「名額只剩 N 個」急迫感設計
- 用 AI 生成圖取代社團自己的作品，或用固定高度 `object-cover` 強行裁切社團作品
- 在工作區與治理後台表格套用過粗邊框與大偏移陰影干擾閱讀
