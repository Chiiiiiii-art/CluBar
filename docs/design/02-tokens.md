# 02｜Design Tokens

> **唯一的值來源是 [`src/app/globals.css`](../../src/app/globals.css) 的 `@theme`。** 本頁只說明每個 token 的用途與限制，不重複維護數值；兩者不一致時以程式碼為準，並修正本頁。
> 架構：原始值（primitive）→ 語意（semantic）→ 元件。元件只能用語意 token（由 `tests/ui-design-tokens.test.ts` 守門）。
> 本頁的「目標值」是方向 A 定案的數值，Phase 2 會寫進 `globals.css`；欄位「現在對應」是目前程式碼中的語意 token 名稱。

## 1. 色彩

所有色彩以 **OKLCH** 定義（明度在感知上均勻，方便推色階、控制對比）。對比值以 WCAG 2.x 公式計算。

| 語意 token | 現在對應 | 目標值（A） | Hex | 用途 | 限制 |

| `surface` | `surface` | `oklch(99.5% 0.004 85)` | `#fffdfa` | 卡片、表單、對話框 | 卡片不可巢狀 |
| `surface-subtle` | `surface-subtle`／`surface-sunken` | `oklch(94% 0.014 82)` | `#f0eae1` | 次要區塊、骨架屏、停用底色 | — |
| `fg` | `fg` | `oklch(23% 0.025 55)` | `#261a12` | 標題、主要文字（濃縮咖啡） | 對 canvas 15.6:1 |

### 1.2 品牌（吧台燈琥珀）

| 語意 token | 目標值 | Hex | 用途 | 對比 |
| :--- | :--- | :--- | :--- | :--- |
| `brand` | `oklch(54% 0.118 62)` | `#9e5c11` | **只用於**主要行動按鈕、目前選取狀態、焦點框 | `on-brand` 在上 5.09:1 |
| `brand-hover` | `oklch(47% 0.106 62)` | `#844b05` | 主要按鈕 hover／active | 6.84:1 |
| `on-brand` | `oklch(99% 0.005 85)` | `#fdfcf8` | 品牌色上的文字與圖示 | — |

| `brand-soft-fg` | `oklch(45% 0.098 62)` | `#7b470b` | `brand-soft` 上的文字、品牌色文字連結 | 對 brand-soft 6.4:1、對 surface 7.55:1 |
| `focus-ring` | 同 `brand` | — | `:focus-visible` 外框 | — |

**品牌色規則**（Apple HIG：品牌色要審慎使用；同一顏色不可代表不同意義）：
- 每個畫面只有一個高飽和色相＝琥珀。領域色是低彩度底色，不算。
- 品牌色＝「可以按／正在選」。不拿來塗標題、裝飾、非互動文字。
- 卡片層級的行動（例如卡片上的「留位子」）用安靜樣式（墨色外框或文字連結），實心琥珀只留給頁面的唯一主要行動。

### 1.4 狀態色

沿用現有 `success`／`warning`／`danger` 與 `notice-*` token。Phase 2 需在米白底上重新驗證對比（目標：文字 ≥ 4.5:1）。狀態一定搭配圖示或文字，不只靠顏色（WCAG 1.4.1）。

## 2. 字體

| Token | 字體 | 用在 | 不可用在 |
| :--- | :--- | :--- | :--- |
| `font-display` | **Noto Serif TC（思源宋體）** 600–700 | 頁面標題、活動與社團名稱、Blend 卡、空狀態標語 | 按鈕、表單、標籤、長段落、治理後台 |
| `font-sans` | Noto Sans TC 400–700 | 其他所有文字 | — |

- 數字（日期、時間、金額）加 `tabular-nums`。
- 中文不加字距、不用斜體；標題行高 1.3、內文 1.7（W3C clreq）。
- 載入：`next/font`、`display: swap`、不預載（CJK 字體依 unicode-range 分片，預載會抓全部分片）。

### 字級階梯

| 名稱 | 大小 | 用途 |
| :--- | :--- | :--- |
| `xs` | 12px | 最小字級；標籤、註記 |
| `sm` | 14px | 次要資訊、按鈕 |
| `base` | 16px | 內文、輸入框（行動版 < 16px 會觸發縮放） |
| `lg` | 20px | 卡片標題 |
| `xl` | 24px | 區塊標題 |
| `2xl` | 32px | 頁面標題（行動版） |
| `3xl` | 40px | 頁面標題（桌機）、Blend 卡主句 |

字重上限 700（`font-bold`）；不使用 800／900。

## 3. 形狀

| 用途 | 圓角 | 說明 |
| :--- | :--- | :--- |
| 標籤、徽章 | 6px（`rounded-md`） | 像菜單標籤，與按鈕區分 |
| 按鈕、輸入框、卡片 | 12px（`rounded-xl`） | 現行實作；原型的 10／14px 差異不明顯，暫不拆分 |
| 對話框、底部面板 | 12–16px | — |
| 篩選 chip、頭像、杯墊 | 完全圓 | — |

**物件形狀語彙**（一種物件一種形狀）：

| 物件 | 隱喻 | 做法 |
| :--- | :--- | :--- |
| 活動 | 票根 | 卡片側邊半圓缺口＋虛線，分隔「時間地點」與「行動」 |
| 社團標誌 | 杯墊 | 圓形、領域色底、細外環；無 Logo 時用社團名稱第一個字 |
| 作品／日常 | 原圖 | 保留原始比例、極少邊框 |
| 篩選 | 菜單標籤 | 圓 chip；選中時琥珀實心 |

陰影：以細框為主，幾乎不用陰影；只有浮在內容上的元素（對話框、提示、底部報名列）用一層柔和陰影。

## 4. 動態

| Token | 值 | 用途 |
| :--- | :--- | :--- |
| `duration-fast` | 120ms | hover、按下 |
| `duration-base` | 200ms | 展開收合、切換 |
| `duration-celebrate` | 320ms | 情緒高點：報名成功蓋章、追蹤、Blend 揭曉 |
| `ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 進場與慶祝 |

- 慶祝動態只在 200–400ms，且只在使用者自己觸發的情緒高點出現。
- `prefers-reduced-motion: reduce` 時只保留透明度變化或完全不動（全域規則已在 `globals.css`；WCAG 2.3.3）。
- 不做：載入時大範圍進場動畫、視差、無意義的 hover 漂浮。

## 5. 間距與版面

- 間距以 4px 為單位，常用 4／8／12／16／24／32／48。
- 內容最大寬度 1152px（`max-w-6xl`）；行動版左右 16px。
- 點擊目標至少 44×44px（WCAG 2.5.8 最低 24px，本專案取 44px）。
- 固定頂欄與底部導覽列不可遮住鍵盤焦點（WCAG 2.4.11；`globals.css` 的 `scroll-padding` 機制要保留）。
