# CluBar UI/UX 視覺重設研究報告：真實案例靈感庫與反 AI 模板策略（v2）

> **文件狀態**：v2 視覺重設研究報告；經實作拍板，最終採用 **路線 1（精修潮流貼紙風）為主軸，融入路線 2 的 Soft Neubrutalism 色彩張力與路線 3 的非圓形貼紙／摺角空狀態**，定案為 **v2.5**（見整合原型 [style-tiles-v2/01-modern-tactile-v2.html](./style-tiles-v2/01-modern-tactile-v2.html) 與正式規範 [docs/design/README.md](../design/README.md)）。
> **背景**：v1 改版把冷灰與 indigo 換成米白紙色與暗土琥珀 `#9e5c11`，但瀏覽起來仍像一般 AI 生成的 Tailwind 網頁模板。本報告拆解原因、彙整 12 個真實產品與台灣在地案例，提出 4 條互異的視覺路線、海報共存法則、3 個新品牌隱喻，以及通過實測的 OKLCH 色票與字體規格。
> **不可破的 4 條底線**：不顯示人氣數字（讚數／人數／排名／契合度）、社團作品與海報原比例不裁切、WCAG 2.2 AA 無障礙、校園正向可信（無夜店酒精／急迫感倒數）。

## 一、為什麼 v1 換色票後還是像「AI Tailwind 模板」？

檢視現況實作（`src/components/DiscoverClient.tsx`、`Navbar.tsx`、`PostCard.tsx`、`EventCard.tsx`）與 v1 設計規範（`docs/design/01-brand.md`、`02-tokens.md`），問題不在配色微調，而在「結構與決策的雙重保守」：

### 1.1 v1 決策的自我矛盾

[UI 改善計畫](./ui-redesign-plan.md) §2.1 引用了 Google **Material 3 Expressive** 的實證研究（46 項研究、超過 18,000 名全球受測者）：**18–24 歲受測者中有 87% 明顯偏好有表現力的設計**，表現力介面讓現代感提升 34%、次文化認同感提升 32%、創新感提升 30%，而且結構化的視覺張力能讓使用者**識別關鍵 UI 元素的速度最快提升 4 倍**。

然而 v1 在最後決策時（`01-brand.md`、`02-tokens.md`、`tests/ui-design-tokens.test.ts`）卻走向極端保守：
- 選定低飽和暗土琥珀 `#9e5c11` 與思源宋體 600–700，同時禁止 `font-extrabold`／`font-black` 與 `rounded-2xl`／`rounded-3xl`。
- 為了「吧台」不聯想到夜店酒精，拿掉所有大膽圖形與裝飾，只剩彩度 0.01 的米白底與灰咖啡細框。
- 連 v1 規範裡寫好的「宋體頁面標題」「領域色貼紙」「杯墊無圖宣示卡」「自繪空杯插圖」，在首頁 `DiscoverClient.tsx` 也幾乎沒出現（首頁無 Masthead 標題、`PostCard.tsx` 仍用素灰底、`EmptyState` 被 Lucide icon 覆蓋）。

### 1.2 AI 模板 6 大病徵 × 反模板 6 大槓桿

| # | AI Tailwind 模板病徵（CluBar 現況） | 反模板視覺槓桿（v2 解法） |
| :--- | :--- | :--- |
| **1. 單一 1px 細框白卡** | 全站所有容器都是 `rounded-xl border border-ink-200 bg-surface`，缺乏物理重量與階層。 | **實體材質邊界**：改用 2–3px 實線邊框＋硬偏移陰影、白色模切貼紙邊（die-cut border）、4px 立體按壓底邊、或雙線刊物格線。 |
| **2. 千篇一律的細線 Icon** | 分頁、提示條、空狀態、Meta 全塞 16px Lucide 細線 icon，一眼看穿是標準元件庫。 | **自繪向量小物＋物理印記**：用社團貼紙、雙圈郵戳杯墊、打孔／鋸齒票根、報名印章、自繪粗筆觸 SVG 插圖取代純工具 icon。 |
| **3. 公式化首屏骨架** | 頂欄 → Tabs → 圓角搜尋條 → 一排圓藥丸 chip → 均等 3 欄卡片，沒有記憶點。 | **有性格的首屏舞台（Masthead）**：用大字視覺張力＋可點貼紙區／校園快訊帶／刊物報頭宣告平台性格，第一眼就知道這是「社團聚」。 |
| **4. 過度安全的低彩度單色** | 整頁只有一種暗橘褐出現一兩次，六大領域色沒當成視覺資產運用。 | **領域色當作貼紙資產**：在保有 WCAG AA 對比的前提下，讓 6 大領域（學術／藝文／康樂／體育／服務／聯誼）以鮮明貼紙色出現在篩選列、無圖貼文卡與社團杯墊上。 |
| **5. 鎖死單一字重與圓角** | 全站 Noto Sans TC 400–700 配 `rounded-xl`，文字與形狀沒有節奏反差。 | **形狀與字體的刻意混搭**：一種物件一種輪廓（圓膠囊／斜角標籤／齒孔票根／扇貝徽章），搭配超粗海報體、圓體粉圓或特粗黑明體＋等寬編號字。 |
| **6. 零物理回饋的點擊** | 只有 `transition-colors`，按下去沒有「按到實體開關／蓋下印章」的爽感。 | **觸覺微動態（Tactile Physics）**：按鈕按下位移吃掉陰影、貼紙 hover 微抬旋轉、報名完成 320ms 蓋章／撕票動畫（皆遵守 `prefers-reduced-motion`）。 |

## 二、真實案例靈感庫拆解（12 個案例 × 4 條視覺路線）

以下案例皆取自公開產品設計系統、官方發表分析與台灣在地大型活動實務，依「實體小物感（貼紙／票根／杯墊／印章）」拆成 4 條截然不同的調性路線。

### 路線 1｜精修潮流貼紙風（Modern Tactile）
> **代表氣質**：乾淨但超好記——年輕大學生覺得潮，校方與競賽評審也覺得專業精良。

| 參考案例 | 學什麼（骨架／字體／觸感） | 不學什麼（反面教材） | 怎麼套進 CluBar |
| :--- | :--- | :--- | :--- |
| **Figma Config**（年度設計大會品牌） | 把數位元件做成真實世界小物——識別吊牌、縫線布章、票根式議程卡、鮮明多色貼紙組搭配嚴謹字級系統。 | 不學開發者專用術語與過多 3D 浮誇特效，避免掩蓋社團作品。 | 首頁頂部像「社團貼紙工作台」，活動卡做成現代登機證雙聯票根，無圖貼文用幾何貼紙卡呈現。 |
| **Bento.me**（個人積木主頁） | 像打開整理好的桌面收納盒：清晰分隔的模組方塊、精準內距、點陣或純淨底襯托多元內容。 | 不學過度均勻的固定方格（會吃掉直式／橫式社團海報比例）。 | 維持瀑布流原圖比例，但用清晰的粗框與點陣筆記本底把「桌面物件感」拉出來。 |
| **Luma**（活動平台） | 厚實紙卡層次、柔和與明確並存的狀態回饋、極好掃讀的時間地點資訊層級。 | 不學參加者總數曝光與偏冷調性科技灰。 | 活動詳情頁把時間／地點／費用／零基礎條件排成一張可直接截圖分享的實體邀請票卡。 |
| **台灣設計展（TDRI）** | 在地字體排印紀律、清晰的視覺導視符號系統、把紀念徽章與幾何貼紙做成社群認同載體。 | 不學過度依賴大型全版動態特效導致手機載入慢。 | 用繁中圓黑／幾何標題字（`Chiron GoRound TC`）＋等寬時間規格（`JetBrains Mono`），領域符號像展覽導視牌。 |

### 路線 2｜粗獷街頭拼貼風（Neo-Brutalism / Campus Zine）
> **代表氣質**：最不像 AI 模板——像大學校園佈告欄貼滿社團海報、紙膠帶與地下音樂祭傳單。

| 參考案例 | 學什麼（骨架／字體／觸感） | 不學什麼（反面教材） | 怎麼套進 CluBar |
| :--- | :--- | :--- | :--- |
| **Gumroad**（創作者市集） | 2–3px 實黑框、零模糊純黑硬陰影（`4px 4px 0 #000`）、高飽和撞色、按下按鈕直接位移吃掉陰影的機械感。 | 不學價格標與銷售數字導流。 | 用粗黑框＋硬陰影建立強烈的實體紙片感；社團海報下方加一塊亮黃／電光藍標籤條立刻跳出畫面。 |
| **Partiful**（Google Play 2024 年度最佳 App） | 數位傳單拼貼感、把報名做成「蓋章／發貼紙」的社交儀式、口語輕鬆的年輕語氣。 | **不學**深色夜店霓虹背景、派對閃爍圖與 Boops 數值回顧。 | 保留淺色再生海報紙底（顧及閱讀與校方觀感），把 Partiful 的拼貼紙膠帶與蓋章式 RSVP 搬進淺色畫布。 |
| **大港開唱（Megaport Festival）** | 高對比強烈色塊碰撞、海報級極粗字體排印（Line-up 資訊密集卻清楚）、限定貼紙與活動手環收藏感。 | 不學演出卡司階級字體大小差異（CluBar 社團一律公平曝光）。 | 頂部採「黑底萊姆黃校園快訊帶」，活動卡用粗框條碼演出票造型，領域色像音樂祭舞台分區貼紙。 |

### 路線 3｜軟 Q 貼紙文具風（Playful Soft / Toy Tactile）
> **代表氣質**：零門檻、最歡迎大一新生——像文具店買得到的立體模切貼紙與玩具按鍵，按下去超療癒。

| 參考案例 | 學什麼（骨架／字體／觸感） | 不學什麼（反面教材） | 怎麼套進 CluBar |
| :--- | :--- | :--- | :--- |
| **Duolingo** | 4px 同色系深色底邊立體按鈕（按下位移 3px）、飽和明快的語意色彩、圓體粗字（Feather / 粉圓感）、即時成就回饋。 | **不學**連勝天數（Streak）、XP 排行榜與情緒勒索提醒。 | 把 4px 立體下壓按鍵用在「留個位子」「搜尋」「換一批」與領域積木，零壓力又超有手感。 |
| **Google Material 3 Expressive** | 打破全站單一圓角，混用大圓角、藥丸、扇貝徽章等有機形狀；彈簧貝茲曲線微互動讓介面活起來。 | 不學過度花俏的動態位移造成使用者暈眩（必須守住 `prefers-reduced-motion`）。 | 同畫面並存圓角 24px 卡片、完全圓形頭像、SVG 扇貝波浪貼紙與波浪虛線票根。 |
| **浪人祭（Vagabond Festival）** | 沿圖案輪廓裁切的 **Die-cut 模切白色邊框貼紙**，把社團／活動元素做成「會想貼在筆電上」的紀念小物。 | 不學搶票急迫感文案與特定夜遊奇幻暗調。 | 所有社團杯墊與領域貼紙都加上 **3.5px 純白模切外框＋柔和投影**，像真正剪下來貼在奶油紙上的貼紙。 |

### 路線 4｜復古印刷潮牌風（Retro Print / Risograph Zine）
> **代表氣質**：文青升級成設計潮牌——把「看社團作品」變成逛獨立印刷刊物展與黑膠唱片行。

| 參考案例 | 學什麼（骨架／字體／觸感） | 不學什麼（反面教材） | 怎麼套進 CluBar |
| :--- | :--- | :--- | :--- |
| **Teenage Engineering** | 像精密硬體面板的格線秩序、等寬規格字體、序號編碼（`NO.042`）與乾脆俐落的開關狀態切換。 | 不學過於冷硬的純黑灰科技感或極小字級（必須 ≥ 12px）。 | 活動時間、地點、費用全部排成售票機等寬規格欄，搭配雙聯票號與印刷檢核線。 |
| **Poolsuite FM / 獨立刊物與 Risograph 印刷** | 孔版印刷（Risograph）有限專色疊印（群青藍 × 螢光朱紅 × 芥末黃）、微錯位雙色套印（misregistration）、新聞紙感米黃底、郵票鋸齒邊與打孔電影票根。 | 不學低對比度復古褪色文字或過小像素字影響中文閱讀。 | 把 v1 偏軟的思源宋體拉升到 `900` 超黑明體大標，搭配朱紅＋群青藍雙色錯位陰影與真實郵票鋸齒票根。 |

## 三、「色彩豐富的社團海報 × 高彩度介面」共存法則

社團自己的海報與照片（如熱舞社表演照、創遊社遊戲截圖、美術社插畫、天文社觀星照）本身已經充滿色彩與字體。介面變有個性後，如何不跟社團海報打架？4 條路線各有專屬「邊界緩衝層」：

1. **精修潮流貼紙風**：每張照片都待在 **2px 深墨框＋純白內框／白卡底** 裡，貼紙只佔角落或標題旁 1 個視覺點；白卡形成天然護城河。
2. **粗獷街頭拼貼風**：用 **3px 純黑粗框＋微傾斜半透明紙膠帶** 把任意花俏海報「釘在海報牆上」，黑框強制收斂海報邊緣，讓混亂變成策展秩序。
3. **軟 Q 貼紙文具風**：用 **22px 大圓角＋純白粗模切邊框** 包裹照片，像相紙貼紙；底部標籤用低彩度奶油粉／薄荷粉襯底深墨字，不搶照片彩度。
4. **復古印刷潮牌風**：圖片外圍保留 **極細雙線刊物相框＋新聞紙白邊＋等寬型錄編號（`FIG. 01`）**，任何風格的海報放進去都像印刷展錄裡的作品圖版。

## 四、擺脫「酒杯吧台」的 3 個新品牌隱喻提案

因為不再受限於「社團吧台」與舊酒杯 Logo，以下提出 3 個能同時說服大學生與校方的品牌隱喻，可搭配最終選定的風格一起拍板：

| 方案 | 品牌隱喻 | 核心視覺符號（取代酒杯） | 為什麼比「吧台」更貼合 CluBar |
| :--- | :--- | :--- | :--- |
| **方案 α（推薦）** | **社團通行證 × 筆電貼紙牆**<br>*(Campus Pass & Sticker Board)* | 圓形杯墊貼紙、打孔入場票根、圓形社團戳章、筆電貼紙集滿簿 | 精準命中「社團貼紙＋票根＋印章」實體小物感；每個學生都懂把喜歡社團的貼紙貼上筆電的歸屬感，且零酒精疑慮。 |
