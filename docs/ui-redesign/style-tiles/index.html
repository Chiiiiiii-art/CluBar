三組視覺變數對照原型（v1 已棄置）

三份原型共用同一套米白紙底、濃縮咖啡墨色、六大領域色票、票根活動卡片與杯墊社團標誌，僅切換「招牌強調色（吧台燈琥珀 vs 酒紅）」與「標題字體（思源宋體 vs jf open 粉圓）」，供團隊直接並排檢視與 Desirability 測試使用。

方案 A · 吧台燈琥珀 × 思源宋體

溫暖、微醺燈光感與刊頭質感

以吧台燈琥珀作為唯一主要行動色，搭配 Noto Serif TC 思源宋體作為大標與票根標題。視覺重心沉穩且有餐酒館菜單般的職人手作感，能讓色彩豐富的新生海報成為畫面主角，同時保留溫暖邀約氛圍。

方案 B · 酒紅 × 思源宋體

深邃醇厚、對比鮮明的聚會邀約

將強調色切換為低明度酒紅（對比度達 8.21:1），同樣搭配思源宋體標題。在米白紙底上具有極高辨識度與儀式感，按鈕與當前篩選狀態一眼可辨，氛圍較為成熟典雅，接近大學裡的文青聚落。

開啟方案 B 原型
方案 C · 吧台燈琥珀 × jf open 粉圓

圓潤親切、與 Logo 線條同頻的青春感

沿用吧台燈琥珀強調色，將標題換成台灣開源的 jf open 粉圓體（經 jsDelivr 載入），筆畫末端的圓角呼應 CluBar Logo 的厚圓角線條。整體語氣更輕快友善、零距離感，對首次逛社團的非社員新生特別親切。
