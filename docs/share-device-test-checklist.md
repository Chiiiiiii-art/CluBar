# 實機測試清單：分享邀請卡與發布中心（第一階段）

> 對應 [one-stop-publish-solution.md](./one-stop-publish-solution.md) 第一階段。這些行為**只能在真手機上驗證**：瀏覽器模擬器沒有 IG／LINE App，桌機 Chrome 的系統分享選單也與手機不同。

## 0. 測試前準備

**Web Share API 只在安全連線（HTTPS 或 localhost）下可用。** 手機用 `http://192.168.x.x:3000` 連開發機時，`navigator.share` 不存在，所有分享都會退回「複製連結」，測不出真正行為。三種做法擇一：

| 做法 | 指令／步驟 | 注意 |
| :--- | :--- | :--- |
| A. Next 內建 HTTPS | `npx next dev --experimental-https -H 0.0.0.0`，手機開 `https://<電腦區網 IP>:3000` | 自簽憑證，手機要手動信任；iOS 可能仍判定不安全 |
| B. 通道服務（cloudflared／ngrok） | 對外開一條 HTTPS 網址指向 3000 | **開發機會暫時對外公開**，測完立刻關；不要用正式資料 |
| C. 部署到測試環境 | 有 HTTPS 的 staging | 最接近正式環境 |

LINE／IG 預覽卡（OG 圖）需要**對外可連的網址**，只有 B、C 能測。

裝置：iPhone（Safari）、Android（Chrome）各一台；兩台都要裝 LINE 與 Instagram 並登入。

## 1. 學生端：分享邀請卡（`/e/<短碼>`）

| # | 步驟 | 預期 | iOS | Android |
| :--- | :--- | :--- | :---: | :---: |
| S1 | 未登入，開活動頁，點「分享邀請卡」 | 跳出系統分享選單，預覽含限動圖片 | | |
| S2 | S1 選 Instagram | IG 開啟並帶入圖片（限動或貼文） | | |
| S3 | S1 選 LINE → 選一個聊天室 | 送出圖片＋文字（含活動網址） | | |
| S4 | S1 按取消 | 不顯示錯誤訊息 | | |
| S5 | 在 LINE 收到的網址點開 | 直接看到活動頁（不需登入），LINE 顯示預覽卡 | | |
| S6 | S5 點「登入報名」→ 完成登入 | 回到同一活動頁並捲到報名區，**不會自動報名** | | |
| S7 | 活動有「隱藏地點」 | 分享文字與預覽卡都不出現地點 | | |
| S8 | 首頁活動卡上的分享圖示 | 分享該活動，不會誤觸進入活動頁 | | |
| S9 | 桌機 Chrome 點「分享邀請卡」 | 有系統分享就開；沒有就顯示「已複製連結」 | — | — |

## 2. 幹部端：發布中心

| # | 步驟 | 預期 | iOS | Android |
| :--- | :--- | :--- | :---: | :---: |
| P1 | 管理頁建立活動 | 出現發布面板（不是只有一行網址） | | |
| P2 | 「發到 LINE」 | 開啟 LINE 選擇聊天室畫面，文字已預填 | | |
| P3 | 「發到 Instagram」 | 文案已複製提示 → 系統分享選單含限動圖 → 選 IG 可貼上文案 | | |
| P4 | 設定 Discord Webhook 後「發到 Discord」 | 頻道出現訊息＋活動卡；顯示成功 | | |
| P5 | Discord 文字中含 `@everyone` | 訊息送出但**不會**提醒全頻道 | | |
| P6 | 移除 Discord 設定 | 出現確認對話框；移除後按鈕改為設定提示 | | |

| P8 | 「放到 IG 個人簡介的連結」複製 → 貼到 IG 個人簡介 → 從 IG 點開 | 開啟社團頁，看得到所有近期活動 | | |

## 3. 記錄

已知風險（測試時特別留意）：
- 圖片在頁面載入／手指碰到按鈕時預先下載；若點擊當下還沒下載完，**這次只分享文字＋連結**（為避免 iOS 判定點擊已過期而拒絕分享）。活動卡上的小分享鈕最常遇到，屬預期行為。
- iOS 分享「圖片＋文字」時，部分 App 只收圖片、丟掉文字。
- IG 從系統分享選單收圖時，不一定直接進限動；可能進貼文或私訊。
- `line.me/R/share` 在未安裝 LINE 的裝置會開網頁版。
